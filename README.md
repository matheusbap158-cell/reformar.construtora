# ReforMar Construtora - Landing page (demo)

Construtora em Pouso Alegre/MG. Página única em HTML/CSS/JS: abra `index.html` no navegador (ou use `node _ferramentas/preview-local.mjs`).

| Caminho | O que é |
|---|---|
| `index.html` | A página inteira |
| `assets/` | Fotos otimizadas (foto-01..10) |
| `Fotos/` | Originais renomeados |
| `Imagens/` | Prints originais enviados |
| `Copy.txt` | Texto usado no site |
| `design-system-reformar-construtora.md` | Tokens provisórios (grafite + laranja) |
| `Info maps.txt`, `Info para copy/` | Dados reais do cliente |

Pendências: ver o fim do `Copy.txt`. Não publicado.
